## What Was Built
A **Plan Pinning** prototype tab under SQL Activity in DB Console. Plan pinning is NOT implemented in the engine - all pinning data is mocked; only execution counts and plan gists from `crdb_internal.statement_statistics` are real.

### Files Modified
- **`pinnedPlans/pinnedPlansPage.tsx`** - Main page with 3 pill-style sub-tabs (All pinned plans, Drift analysis, Audit log)
- **`pinnedPlans/start-dev.sh`** - Startup script
- **`pinnedPlans/spec.md`** - Engineering specification
- **`statementDetails/planDetails/planDetails.tsx`** - Explain plan view with pin/unpin button + badge
- **`statementDetails/planDetails/plansTable.tsx`** - Plan table with "Plan pin status" column
- **`statementDetails/statementDetails.tsx`** - Summary card "Plan pin status" row with counts
- **`statementsTable/statementsTable.tsx`** - Statements list "Plan pin status" column with counts
- **`db-console/src/views/sqlActivity/sqlActivityPage.tsx`** - "Pinned plans" tab in SQL Activity

### Key Design Decisions
- All text is **sentence case** throughout
- Badge labels: **Pinned**, **Unpinned**, **Invalid pin** (no icons in badges)
- Statement-level badges always show count: "Pinned (2)", "Invalid pin (1)"
- Badge height: 28px in tables, 24px in summary card
- Plan detail badge fontWeight 400; table badges fontWeight 600
- Sub-tabs use **pill style** (rounded, blue fill) — distinct from parent underline tabs
- Pin button is **icon-only**, `padding: 6px`, 14px pin SVG, `1px solid #c0c6d9` border
- Summary metric cards at top were **removed**
- Drift analysis lives only on Pinned Plans page (removed from explain plan page)
- Pin badge removed from Statement Fingerprint header (only in summary card)
